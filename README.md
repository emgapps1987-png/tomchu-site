# Tomchu Tattoo – אתר

אתר סטטי (HTML/CSS/JS בלי תלויות) עבור www.tomchu-tattoo.co.il.

- `tools/build.py` – מחולל העמודים (תוכן, SEO, JSON-LD, sitemap). הרצה: `python3 tools/build.py`
- `tools/optimize_images.py` – הכנת תמונות WebP/JPEG מתמונות האפליקציה
- `tools/content.json` – תוכן (עבודות, שאלות, מאמרים, החלמה) שיוצא מהאפליקציה
- `assets/css/site.css`, `assets/js/site.js` – עיצוב והתנהגות

פריסה: GitHub Pages מתיקיית השורש (קובץ CNAME כלול).
